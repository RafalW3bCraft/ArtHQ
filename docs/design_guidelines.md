# ArtHQ design guidelines

The canonical visual system and interaction rules are documented in [DESIGN.md](DESIGN.md), with machine-readable values in [design-tokens.json](../design-tokens.json) and a local preview in [design-preview.html](../design-preview.html).

- ArtHQ is an English-language website and app studio and a subsidiary of RafalW3bCraft.
- Keep a warm editorial surface, dark ink text, an amber/rust accent, and clear type hierarchy. Use the local Inter and Fira Code fonts adapted from the archive, with Bricolage Grotesque for display headings.
- Present the six verified projects in a horizontal, auto-advancing carousel with touch and keyboard controls. Pause on hover, focus, or manual interaction. Respect reduced-motion preferences.
- Use motion to clarify navigation and state. Keep content visible if JavaScript or Intersection Observer is unavailable. Do not use 3D models, WebGL, custom cursors, or continuous decorative motion.
- Keep visible focus, semantic controls, contrast, readable form labels, and 44px minimum controls. Keep client and staff screens consistent with the public site.
- Use factual descriptions only. Do not publish client testimonials without the exact quote, attribution, and permission.
